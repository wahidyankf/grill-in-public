# opencode Skills

opencode discovers these skills automatically from this directory. It also reads `.claude/skills/` and `.agents/skills/`, so a skill kept in one of those is already available to it; the copy here exists so the directory is complete on its own.

## Available Skills

- [`grill-me/`](grill-me/SKILL.md) — resolves open decisions by asking the owner structured multiple-choice questions. Use it when work is blocked on a decision, or when the owner asks to be grilled on a design.

Each skill is mirrored in [`.claude/skills/`](../../.claude/skills/README.md) and [`.agents/skills/`](../../.agents/skills/README.md) and must stay at parity; see the [harness capability parity policy](../../repo-governance/conventions/harness-capability-parity-policy.md).
